## 当前判断

我不建议第一步就用 ChatGPT Sites **完全替代** Windows EXE。更合适的是先做“私人 Web 主站 + 本地辅助端”的混合方案：

- Sites：工具首页、三个文本过滤器、数据中心、历史、表格 CRUD、文件导入导出、MissAV 番号过滤及浏览器脚本生成。
- 本地辅助端：Telegram 个人 API 会话、需要本地代理的操作、Chrome 扩展和可能遭遇网站限频的 123AV 账号操作。
- 等 Web 版稳定后，再决定是否把 Telegram Bot 和部分查询任务迁到云端。

原因：当前项目不是普通网页，而是 Vue 前端 + Tauri/Rust 后端 + 本机 SQLite + Windows DPAPI + 本地 Chrome 桥。ChatGPT Sites 可以提供持久数据库、文件存储、身份和秘密变量，但不能直接运行现有 Rust/Tauri 后端；某些框架、私有网络、后台服务和托管方式目前也不受支持。
