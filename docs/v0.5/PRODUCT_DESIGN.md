# TG 内容工具箱 v0.5 产品设计

状态：正式主线实现

分支：`codex/v0.5-redesign`

## 产品边界

v0.5 将旧版堆叠式工作台改为“工具优先”：首页只选择工具，进入后只展示该工具的输入、执行、结果和处理历史。数据、来源、日志、设置是公共入口，不把所有功能堆在侧边栏。

五个工具相互独立：推特博主、Bad.news、海角、MissAV、123AV。文本工具不写入永久番号库；MissAV 和 123AV 只共享输入规范化与统一数据管理，不会自动互相启动。

## 已实现架构

| 层 | 技术 | 职责 |
| --- | --- | --- |
| 桌面壳 | Tauri 2 / WebView2 | Windows 窗口、文件选择与单 EXE 构建 |
| 前端 | Vue 3 / TypeScript | 工具工作区、表格、多选、进度与历史 |
| 核心 | Rust | 命令白名单、网络请求、Chrome 桥、Telegram API、迁移和备份 |
| 数据 | SQLite / WAL / FTS5 | 永久库、处理历史、来源、映射与日志 |

前端只能调用经过校验的 Rust 命令；不能直接访问数据库、任意路径或网络。数据库写操作会校验关联、唯一键、数字/JSON 字段，并在有破坏风险时自动备份。

## 核心工作流

```text
TG 文件 / 个人 API / Bot / 手动输入
        ↓
工具独立过滤和可选时间范围
        ↓
结果表 + 一行一个输出 + 可编辑处理历史
        ↓
MissAV：查询 → 标签 → 永久库 → Raindrop
123AV：查询 → Chrome 扩展 / 内置串行助手 / CSV
```

Telegram 个人 API 和 Bot 同时保留。个人 API 支持二维码、手机号验证码、2FA、群组/超级群/频道、每来源检查点和 100 来源上限；Bot 是较轻的增量通道。历史导出文件与 API 输入使用同一消息结构，避免规则分叉。

Raindrop 支持用户多选 Collection 后的 Pull、Push 与双向同步；全账号番号身份预检不因 Collection 位置变化制造重复。Pull 合并远端 Tags，Push 可新建或更新；双向模式根据本地、远端和成功快照判断方向与冲突。

123AV 同站账号操作严格单路；Chrome 扩展是自动方式，APP 内方式为明确的人工串行助手，另有只导出。其他网站不被 123AV 限流暂停。

## 兼容与迁移

v0.5 的默认文件名为 `tg-content-toolbox-v05.sqlite`。若发现早期 `prototype-v05.sqlite` 或早期 `com.wjl.tg-content-toolbox.next` 数据目录，首次启动会安全转存 v0.5 数据、个人 Telegram 凭据与会话；v0.4.5 旧库必须由“v0.4.5 数据迁移”页面显式选择，始终以只读方式打开，迁移前自动备份并完整归档旧表。

绝不在自动测试、开发启动或包冒烟中访问用户的 v0.4.5 正式数据库。
